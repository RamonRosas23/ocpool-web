# OCPOOL — Documentación histórica

Esta carpeta conserva planes, especificaciones y revisiones de fases anteriores. Sirve como registro de decisiones y evidencia de cómo evolucionó el producto; no es una cola activa de tareas.

La documentación vigente de la rearquitectura comercial se encuentra en [`../ocpool-commercial-v2/`](../ocpool-commercial-v2/).

## Organización

- `plans/` — planes de implementación de fases cerradas o sustituidas.
- `reviews/` — revisiones y auditorías históricas.
- `specs/` — especificaciones de fases anteriores.

Cuando un documento histórico contradiga la documentación V2, prevalecen el ADR posterior, el plan V2 y [`PROJECT_STATUS.md`](../../PROJECT_STATUS.md).
